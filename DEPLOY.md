# Deploying Mapa de IA (self-hosted)

Three services via Docker Compose: **Postgres/PostGIS**, the **FastAPI** backend,
and **Caddy** (serves the SvelteKit SPA and reverse-proxies the API). A one-shot
**loader** populates the database from the pipeline artifacts.

```
┌──────────┐   /api,/auth,/users   ┌──────────┐        ┌────────────┐
│  Caddy   │ ────────────────────► │ backend  │ ─────► │ Postgres   │
│ (SPA +   │                       │ FastAPI  │        │ + PostGIS  │
│  TLS)    │ ◄─ static SvelteKit   └──────────┘        └────────────┘
└──────────┘                             ▲
                                   loader │ (one-shot, `06_load_db.py`)
```

## 1. Prerequisites

- Docker + Docker Compose on the host (UFPel VPS).
- The pipeline artifacts in `./data/` (git-ignored). Either run the pipeline
  (`files/01`–`05`) or download the release bundle used by the legacy app:
  `raw/sbc_articles.parquet`, `clean/researchers_with_topics.parquet`,
  `output/researchers_geo.json`, `output/institutions_geo.json`,
  `output/coauthorship.json`, and `brazil_states.geojson`.

## 2. Configure

```bash
cp .env.example .env
# Edit .env:
#   SECRET_KEY   → openssl rand -hex 32   (REQUIRED — see note below)
#   SITE_ADDRESS → your domain (auto-HTTPS) or ":80" for local HTTP
#   CORS_ORIGINS → https://your-domain  (or http://localhost)
#   POSTGRES_PASSWORD → a strong value
```

> **SECRET_KEY is mandatory.** The API refuses to start (and its healthcheck
> never passes) if `SECRET_KEY` is unset, a known placeholder, or shorter than
> 32 characters. Generate one with `openssl rand -hex 32`.

> **Keep `WEB_CONCURRENCY=1`.** The API cache is per-process (`backend/app/cache.py`),
> so extra workers each hold their own cache and pipeline invalidation
> (`data_version` bump) only reaches one of them. Scale out only after moving the
> cache to a shared store (e.g. Redis).

For the demographic-map choropleth, copy the states polygons into the SPA:

```bash
cp data/brazil_states.geojson frontend/static/brazil_states.geojson
```

(The map still works without it — states just won't be shaded.)

## 3. Bring up DB + backend (runs migrations automatically)

```bash
docker compose up -d --build db backend
# backend entrypoint runs `alembic upgrade head` before serving.
```

## 4. Load the data (one-shot)

```bash
docker compose run --rm loader
```

This runs `files/06_load_db.py` with `ALLOW_DB_RELOAD=1` (truncate-and-reload).
Watch the reconciliation report — expected on the current artifacts:

| metric | value |
|--------|-------|
| researchers | 8,898 |
| articles | 3,597 |
| coauthorship_nodes | 8,898 |
| coauthorship_edges | ~23,098 |
| unmatched_graph_nodes | 0 |
| ungeocoded_researchers | 605 |
| collapsed_accent_variant_nodes | ~158 |

> The loader re-normalizes the stale `coauthorship.json` node ids (generated by an
> older accent-preserving normalization) so the full graph is recovered rather
> than ~37% of edges dropped. The upstream fix is to re-run `files/04_explore.py`.

Re-running the loader any time is safe and deterministic. It never touches
`user`, `saved_searches`, `favorites`, or `analytics_events`.

## 5. Start the frontend/edge

```bash
docker compose up -d --build frontend
```

Visit `https://your-domain` (or `http://localhost`).

## 6. Create an admin (optional)

Register via the UI (`/login`), then promote in the DB if needed:

```bash
docker compose exec db psql -U mapadeia -d mapadeia \
  -c "UPDATE \"user\" SET is_superuser = true WHERE email = 'you@ufpel.edu.br';"
```

## Updating the dataset later

Re-run the pipeline to refresh `./data/`, then:

```bash
docker compose run --rm loader   # bumps meta.data_version → API caches refresh
```

## LGPD notes

- Analytics are anonymous (random session id) and gated behind a consent banner;
  no IP/user-agent is stored.
- Account deletion sets `analytics_events.user_id = NULL` (keeps aggregates) and
  cascades `saved_searches` / `favorites`.
- Schedule a retention purge, e.g. monthly:
  `DELETE FROM analytics_events WHERE created_at < now() - interval '365 days';`

## Local development (without Docker)

```bash
# Backend
cd backend && pip install -r requirements.txt
export DATABASE_URL=postgresql+psycopg://mapadeia:mapadeia@localhost:5432/mapadeia
alembic upgrade head
uvicorn app.main:app --reload

# Loader
ALLOW_DB_RELOAD=1 python files/06_load_db.py      # or --dry-run to shape only

# Frontend (Vite dev-proxies /api to :8000)
cd frontend && npm install && npm run dev
```
