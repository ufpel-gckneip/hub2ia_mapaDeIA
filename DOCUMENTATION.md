# Mapa de IA — Technical Documentation

Reference for the refactored system: a Python data pipeline feeding a self-hosted
web app (PostgreSQL/PostGIS + FastAPI + SvelteKit). For running it, see
[`LOCAL.md`](LOCAL.md) / [`DEPLOY.md`](DEPLOY.md); for the pipeline internals, see
[`docs/pipeline.md`](docs/pipeline.md).

Figures below were measured from the committed artifacts.

---

## 1. Architecture

```
Python pipeline (files/01–05)  ──►  data/*.parquet, data/output/*.json
                                          │
                    files/06_load_db.py   │  truncate-and-reload
                                          ▼
                         PostgreSQL + PostGIS   ◄── Alembic migrations
                                          │
                         FastAPI (backend/app)  — REST, JWT auth, tracking, cache
                                          │  /api /auth /users
                                          ▼
                         SvelteKit SPA (frontend) served by Caddy,
                         which also reverse-proxies the API
```

- **Pipeline** stays Python — the right tool for scraping + embeddings/clustering.
  Its output are files; nothing in the pipeline changed except the added loader.
- **Database** is the single source of truth at runtime; holds research data,
  user accounts, and analytics.
- **Backend** ports the old in-memory pandas filtering to server-side SQL.
- **Frontend** replaces the old Streamlit app with a real SPA and purpose-built
  map/graph libraries.

## 2. Data pipeline (`files/`)

Jupytext `# %%` scripts, run top-to-bottom from the repo root:

1. `01_crawl_sbc.py` — crawl SOL (OJS) event proceedings → `data/raw/sbc_articles.parquet`.
2. `02_clean_data.py` — explode authors, normalize names (lowercase, de-accent),
   dedup by exact normalized name → `researchers.parquet`.
3. `03_extract_topics.py` — MiniLM embeddings → UMAP(10-d) → HDBSCAN → TF-IDF
   labels → `researchers_with_topics.parquet`.
4. `04_explore.py` — stats, word cloud, co-authorship graph + spring layout →
   `coauthorship.json` (+ GEXF, PNGs).
5. `05_geocode.py` — affiliation → coordinates via a ~500-institution curated
   dictionary → `researchers_geo.json`, `institutions_geo.json`.
6. **`06_load_db.py` (new)** — loads all artifacts into Postgres.

Requires `umap-learn` (added to `requirements.txt`). The NLP stack needs only
CPU torch.

## 3. Database (`backend/app/models.py`, `backend/alembic/`)

Alembic owns the DDL (extensions `postgis/citext/pg_trgm/pgcrypto`, tables,
indexes, and the generated FTS column). The first migration builds the schema
from the models.

**Research tables:** `events`, `topics` (PK = HDBSCAN cluster id, incl. `-1`
noise), `institutions` (PostGIS `geometry(Point,4326)`), `articles` (generated
`tsvector` + GIN for full-text), `researchers` (surrogate PK + `normalized_name
CITEXT UNIQUE`, trigram index on `display_name`, nullable geom/state),
`authorships`, `researcher_institutions`, `researcher_events`,
`coauthorship_edges` (canonical `src<dst`), `coauthorship_nodes` (nullable FK to
researchers), `meta` (`data_version` for cache invalidation).

**Auth + tracking:** `user` (fastapi-users UUID schema + profile), `saved_searches`,
`favorites`, `analytics_events` (nullable user, anonymous `session_id`, JSONB
payload). LGPD: account deletion `SET NULL`s events (keeps aggregates) and
cascades user data; analytics need a retention purge job.

Design notes: surrogate researcher PK keeps the 23k-edge FKs small; `state` is
`varchar(32)` (holds either a UF or a country for international affiliations);
international/ungeocoded rows are modeled with **nullable** columns/FKs rather
than dropped, so gaps are queryable.

## 4. The loader & the graph-normalization fix (`files/06_load_db.py`)

Truncate-and-reload with explicit surrogate keys assigned in Python (so FKs
resolve without round-trips), one transaction, guarded by `ALLOW_DB_RELOAD=1`.
A `--dry-run` shapes every row and asserts counts/FK-integrity **without a DB**.
User tables are never touched by a reload.

**Important discovery.** The committed `coauthorship.json` was generated by an
older normalization that only lowercased (kept accents), while the researcher
keys are accent-stripped. A naive load silently dropped ~1,980 nodes and ~8,686
edges (37% of the graph). The loader **re-normalizes** graph node/edge ids to the
canonical researcher key, recovering the full graph (0 unmatched nodes) and
collapsing ~158 accent-variant duplicates. Upstream fix: re-run `04_explore.py`.

Reconciliation the loader logs each run: unmatched graph nodes, ungeocoded
researchers (605), institution collisions, merged duplicate articles.

## 5. Backend API (`backend/app/`)

FastAPI + async SQLAlchemy. Near-static endpoints are cached in-process, keyed on
`meta.data_version`.

- **Researchers:** `GET /api/researchers` (filter topic/min_articles/state/event/q/
  year, paginated), `/{id}`, `/{id}/coauthors`.
- **Map:** `/api/map/institutions` (one marker per university, filtered),
  `/api/map/institution-authors` (authors of one university), `/api/map/researchers`
  (geo points, bbox), `/api/map/state-aggregates` (choropleth), `/api/map/arcs?level=
  state|institution|author` (co-authorship arcs at three granularities).
- **Topics / graph / articles / stats:** `/api/topics`, `/api/graph?min_degree=`
  (full precomputed graph for Sigma), `/api/articles` (FTS) + `/{id}`, `/api/stats`.
- **Auth (fastapi-users):** `/auth/jwt/login|logout`, `/auth/register`,
  `/auth/forgot-password`, `/auth/verify`, `/users/me`.
- **Per-user:** `/api/me/saved-searches`, `/api/me/favorites`.
- **Tracking:** `POST /api/events` (optional JWT or anonymous session; 202).
- **Admin (superuser):** `/api/admin/overview|events|users`, promote user.

## 6. Frontend (`frontend/`)

SvelteKit SPA (`adapter-static`), served by Caddy which proxies the API.

- **Demographic map** — MapLibre GL (OpenFreeMap basemap, no API key) + deck.gl.
  Default layer = one dot per **university**; clicking flies to the city and fans
  the authors out in a **fixed-pixel** phyllotaxis spiral around the hub, with
  spider legs and a per-author detail drawer. Other universities stay visible and
  clickable. Overlays: state choropleth + selectable co-authorship arcs
  (state/university/author) with a min-strength slider.
- **Graph** — Sigma.js + graphology, full graph with a min-degree control.
- **Tables/topics/stats/articles**, **auth UI**, **admin dashboard**, and a
  consent-gated tracking client.

Basemap tiles are OpenFreeMap (data © OpenStreetMap, ODbL — attribution shown by
MapLibre); self-hostable for production independence.

## 7. Known limitations (carried over from the source data)

- **Author disambiguation is exact-name only** — common names over-merge;
  initial-vs-full variants split the same person. Biggest data-quality lever.
- **Geocoding granularity** — a researcher is placed at their *first* affiliation;
  institutions the dictionary maps to the same city coordinate overlap; ~7% of
  affiliations are unmatched (Nominatim fallback disabled) and those researchers
  have no location.
- **Topic labels** — bilingual corpus vs. an English-leaning model and a
  Portuguese-only stopword list; single-word cluster labels can be opaque.

## 8. What the refactor changed vs. the old Streamlit app

- Server-side SQL filtering/pagination instead of loading everything into pandas
  per rerun; heavy graph served precomputed/cached.
- Real DB (accounts, favorites, saved searches, analytics) — things a static app
  couldn't store.
- Fixed the silent 37% graph-edge loss (normalization mismatch).
- Replaced Folium (8k inlined markers) with deck.gl, and pyvis (temp-file leak)
  with Sigma.js; added the university→author drill-down the old flat map lacked.
- Authoritative state handling still pending (see the planned PostGIS `states`
  table for point-in-polygon assignment).
